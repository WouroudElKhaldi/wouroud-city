Fonts for the 3D labels

- inter-400.woff, inter-700.woff: Inter (Latin subset, via Fontsource), SIL Open Font License 1.1, see LICENSE.txt
- inter-arabic-400.woff: Inter Latin merged with Noto Sans Arabic (Arabic subset, via Fontsource) using fontTools, both SIL Open Font License 1.1, see LICENSE.txt and LICENSE-noto-sans-arabic.txt
- All three also carry symbol glyphs (arrows, check marks, stars, shapes, math signs) taken from DejaVu Sans / DejaVu Sans Bold and merged in with fontTools; DejaVu fonts are free to use, modify and redistribute, see LICENSE-dejavu.txt
